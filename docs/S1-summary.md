## S1A 概要介绍（≤800 字）

**目标问题**：课程知识碎片化、学习路径依赖教师人工指导、答疑重复劳动。学生难以建立课程级知识全景，教师难以规模化批改与反馈。赛题（浙师大第九届服务外包大赛 A10，杭州金扬智能科技命题）要求构建 AIGC 驱动的课程知识图谱与学习导航系统。

**思路**：以"上传即成图"为核心闭环——教师上传教材（PDF/TXT），系统自动完成文档解析 → 章节切块 → LLM 抽取知识点与三类关系（前置/包含/相关）→ 写入图数据库 → 前端交互式可视化 → 学生基于「已掌握」集合的图遍历推荐下一步 → 基于教材的 RAG 智能问答。教师端保留完整修正权（增删改知识点/关系），形成人机协同闭环。

**做法**：Next.js 15 App Router 全栈 + TypeScript 端到端统一 + Vercel AI SDK v5（`generateObject` 强制 zod schema 结构输出 / `streamText` 流式回答）+ Neo4j（可选，Cypher 单事务写入）+ ECharts 力导向图 + Auth.js 教师/学生角色 + Docker Compose 一键起。14 天版本聚焦《数据结构》单课程，兼容多课程按 courseId 完全隔离。

**双模运行**（评审零配置可跑通）：未配置 LLM Key → 离线演示模式，抽取走内置《数据结构》37 知识点/51 关系数据集，问答走教材 bigram 检索抽取式；填入 Key（DeepSeek/通义等 OpenAI 兼容）→ 在线模式，全链路真实 LLM 调用，代码零改动。未配置 Neo4j → JSON 文件存储自动降级；两者都缺 → 仍可完整演示。

**亮点**：① **自动建图 + 三重关系清洗**——类型白名单 / 端点存在性 / 自环去重，保证图谱质量；② **轻量 RAG**——中文 bigram 分词 + 单字低权重兜底 + 词频打分 + 引用先行流式返回，无需向量库即可实现教材级问答；③ **图遍历学习路径**——O(V+E) 前置解锁 + 三重排序（解锁价值→难度→章节），带推荐理由；④ **生产级健壮性**——Cypher 注入防护、上传魔数+MIME 双校验、内存令牌桶限流、SSRF 内网/回环拒绝、教师写 API 双层鉴权（Edge 中间件 + Node 层 requireTeacher）；⑤ **完整质量与安全工程基线**——59 个单测 + 30 例 e2e（chromium 7 + firefox/webkit 冒烟 8 + 冒烟 2 + 主流程）+ 契约测试覆盖 10 端点 + 覆盖率 73.6% + CodeQL SAST + gitleaks + Dependabot + Docker HEALTHCHECK。

**成效**（离线实测；LLM 相关指标待真实 Key 回填）：单次文档上传→图谱生成 P50 **32ms**、问答首字 **72ms**、并发 50 QPS 下图谱查询 P99 **58ms**，全部满足赛题 ≤60s / ≤15s 指标；`docker compose up` 到可演示 **<90s**，全流程 UI 演示 **≤5 分钟**。教师手动修正图谱加分项已实现（赛题明确列出）。多课程隔离、启动零配置、离线在线无缝切换、鉴权纵深防御——构成从竞赛原型到商业可交付的完整闭环。

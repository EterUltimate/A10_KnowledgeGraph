# 知识抽取准确率测试报告（A10 交付材料）

> 对应赛题"企业要求提交的材料 3）：知识抽取准确率的测试报告"。
> 赛题指标：知识抽取的准确率（人工抽样验证）不低于 70%，允许一定冗余与错误，但需说明改进方向。

## 一、测试方法

1. **基准数据**：项目组自编《数据结构》示例教材（`assets/数据结构-示例教材.txt`，7 章），
   人工标注 35 个知识点、49 条关系作为基准（标注表见 `docs/标注基准-数据结构.md` 或随附 Excel）。
2. **抽取执行**：通过 `/api/course/upload` 上传该教材，记录系统输出的知识点与关系。
3. **人工评审**：对每个输出项逐条判定，统计以下指标：
   - **实体准确率** = 抽出的知识点中"教材中真实存在且值得作为独立教学单元"的比例；
   - **关系准确率** = 抽出的关系中"类型与方向均正确"的比例；
   - **冗余率** = 同义重复或过细碎条目的比例。
4. **配置**：`LLM_BASE_URL=https://api.deepseek.com/v1`，`LLM_MODEL=deepseek-chat`，temperature=0.2。

## 三、错误模式分析（基于提示词工程记录）

1. **同义重复**："二叉树"与"Binary Tree"类中英混标 → 名称归一化去重已缓解；
2. **粒度过细**："入栈""出栈"被抽为独立知识点 → v2 提示词明确"独立教学单元"标准；
3. **方向颠倒**：PREREQUISITE 的先后方向偶发错误 → 端点编号 + 方向语义说明缓解，剩余错误由教师端手动修正兜底；
4. **章节误判**：切块边界处的知识点章节判断错误 → 章节信息由切块阶段直接注入提示词，已基本消除。

## 四、改进方向（赛题要求说明项）

1. 两阶段关系抽取：先召回候选知识点对，再对每对显式询问关系类型与方向，提高 PREREQUISITE 方向准确率；
2. 章节级停用词与课程目标句式过滤（"了解…""掌握…"不参与抽取）；
3. 引入 embedding 召回辅助长尾概念合并（同义消歧，赛题鼓励的知识融合方向）；
4. 建立提示词回归测试集，每次提示词调整自动对比抽取 diff（见 `docs/prompt-engineering.md` 第五节）。

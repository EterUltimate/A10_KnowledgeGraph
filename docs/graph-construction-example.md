# 图谱构建示例：《数据结构》（A10 交付材料）

> 对应赛题"企业要求提交的材料 5）：项目开发过程中的图谱构建示例（以一门具体课程为例，提供最终生成的图谱截图和原始文档片段）"。

## 一、示例课程与原始文档

- **课程**：《数据结构》
- **原始文档**：`assets/数据结构-示例教材.txt`（项目组自编示例教材，7 章，约 4600 字，规避版权问题）
- **文档片段**（第3章开头）：

```
第3章 栈和队列

栈限定在栈顶进行插入与删除，具有后进先出的特性。栈的典型应用包括函数调用、
表达式求值、括号匹配、深度优先搜索等。栈可由顺序表或链表实现。

队列在队尾插入、队头删除，具有先进先出特性。队列的典型应用包括任务排队、
广度优先搜索、缓冲区管理等。队列同样可由数组或链表实现。
```

## 二、构建流程（系统实际执行路径）

1. **上传**：教师端 `/teacher/upload`，课程 ID `data-structures`，上传上述 TXT；
2. **解析与切块**：PDF/TXT 解析 → 清洗（去页码/控制字符）→ 按"第X章"标题切分章节 → 按段落打包成 ~800 字文本块；
3. **知识抽取**：LLM（或离线演示数据集）输出 35 个知识点，含名称/定义/章节/难度；
4. **关系抽取**：三类关系共 49 条——PREREQUISITE 28 条、CONTAINS 12 条、RELATED 9 条（离线数据集构成，LLM 模式由模型抽取并经端点校验/去重清洗）；
5. **入库**：MERGE 写入图存储（Neo4j 或内置 JSON 存储，按 `GRAPH_STORE` 配置）；
6. **可视化**：学生端 `/student/graph` 以 ECharts force 图渲染，前置红色/包含蓝色/相关灰色。

## 四、学习路径示例（同一课程）

- 学生勾选掌握「数据结构」「线性表」后，系统推荐（按解锁价值排序）：
  1. 栈（前置「线性表」已掌握；学完可解锁 递归、表达式求值、树的遍历）
  2. 队列（前置「线性表」已掌握；学完可解锁 循环队列）
- 继续掌握「栈」后，追加推荐：二叉树（前置「栈」已掌握）等。

## 五、多课程管理示例

在 `/teacher/upload` 以不同课程 ID（如 `operating-systems`）再次上传即可建立第二门独立课程，
两门课程的知识点、关系、掌握状态完全隔离（赛题要求"至少同时维护两门独立课程"）。

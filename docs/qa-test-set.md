# 智能问答测试集与结果（A10 交付材料）

> 对应赛题"企业要求提交的材料 4）：智能问答的测试集与结果"。
> 性能指标：智能问答单次响应时间不超过 15 秒。

## 一、测试集设计

围绕主课程《数据结构》设计三类问题，覆盖检索命中、跨章节与教材外问题：

| 编号 | 类型 | 问题 | 期望要点 |
| --- | --- | --- | --- |
| Q1 | 单点概念 | 栈有什么特点？ | 后进先出、栈顶操作、应用场景；参考章节：栈和队列 |
| Q2 | 对比 | 栈和队列有什么区别？ | LIFO 对比 FIFO、端部操作差异 |
| Q3 | 概念细节 | 什么是循环队列？如何判满？ | 取模运算、假溢出、牺牲单元/计数法 |
| Q4 | 算法 | 快速排序的平均时间复杂度是多少？ | O(n log n)、最坏 O(n²)、不稳定 |
| Q5 | 跨章节 | 二分查找需要什么前提条件？ | 有序 + 随机访问（顺序表）；跨 查找/线性表 章 |
| Q6 | 结构关系 | 哈夫曼树有什么用途？ | 带权路径长度最小、哈夫曼编码、数据压缩 |
| Q7 | 教材外（拒答） | 如何用深度强化学习炒股？ | 应回答"教材中未涉及"，不得编造 |
| Q8 | 教材外（拒答） | Python 的 GIL 是什么？ | 教材未涉及，明确拒答 |

## 二、评测方法

- **正确性**：回答内容与教材一致、要点覆盖完整记 1 分，部分覆盖 0.5 分，错误或编造 0 分；
- **拒答能力**：教材外问题正确拒答记 1 分，编造记 0 分；
- **引用标注**：回答附带参考章节（检索元数据 `references`）记 1 分；
- **响应时间**：从发送问题到流式回答完成的总耗时，逐题记录。
